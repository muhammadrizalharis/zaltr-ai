# CALYZR.AI

> Semua AI terbaik dalam satu ruang kerja pribadi — chat, coding, gambar, video, dan musik.

Aplikasi web pribadi berbasis **Next.js** (App Router) + **Prisma/PostgreSQL**. Akses **khusus undangan**, self-hosted.

## Pengembangan

Semua konfigurasi dan kredensial berada di `.env` (tidak di-commit — lihat variabel yang dibutuhkan di kode).

```bash
npm install
npm run dev      # mode pengembangan
npm run build    # build produksi
npm test         # jalankan unit test
```

## Catatan

- Kredensial, arsitektur, dan detail operasional **tidak** disimpan di repo publik.
- Kontribusi bersifat privat (undangan).
